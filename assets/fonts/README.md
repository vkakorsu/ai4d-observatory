# Fonts for generated share images

Static WOFF files used by `src/lib/og.tsx` to render Open Graph images (Satori reads WOFF, not WOFF2).
Newsreader and IBM Plex are licensed under the SIL Open Font License 1.1. Copied from the
`@fontsource/newsreader`, `@fontsource/ibm-plex-sans` and `@fontsource/ibm-plex-mono` packages.
